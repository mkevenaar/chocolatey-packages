## Usage

To install SCARM, run the following command:

```powershell
choco install scarm
```

To upgrade SCARM, run the following command:

```powershell
choco upgrade scarm
```

To uninstall SCARM, run the following command:

```powershell
choco uninstall scarm
```

## Description

SCARM means Simple Computer Aided Railway Modeller – software for easy and
precise design of model train layouts and railroad track plans.

**Please Note**: This is an automatically updated package. If you find it is
out of date by more than a day or two, please contact the maintainer(s) and
let them know
[package update issues](https://github.com/mkevenaar/chocolatey-packages/issues)
that the package is no longer updating correctly.
