## Usage

To install DevManView, run the following command:

```powershell
choco install devmanview
```

To upgrade DevManView, run the following command:

```powershell
choco upgrade devmanview
```

To uninstall DevManView, run the following command:

```powershell
choco uninstall devmanview
```

## Description

DevManView is an alternative to the standard Device Manager of Windows, which
displays all devices and their properties in flat table, instead of tree viewer.

In addition to displaying the devices of your local computer, DevManView also
allows you view the devices list of another computer on your network, as long as
you have administrator access rights to this computer.

DevManView can also load the devices list from external instance of Windows and
disable unwanted devices.

This feature can be useful if you have Windows operating system with booting
problems, and you want to disable the problematic device.
