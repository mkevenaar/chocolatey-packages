## Usage

To install Veeam Service Provider Console Veeam Updater Plugin, run the
following command:

```powershell
choco install veeam-service-provider-console-updater-plugin
```

To upgrade Veeam Service Provider Console Veeam Updater Plugin, run the
following command:

```powershell
choco upgrade veeam-service-provider-console-updater-plugin
```

To uninstall Veeam Service Provider Console Veeam Updater Plugin, run the
following command:

```powershell
choco uninstall veeam-service-provider-console-updater-plugin
```

## Description

### Exit when reboot detected

When installing / upgrading these packages, I would like to advise you to enable
this feature `choco feature enable -n=exitOnRebootDetected`

### About Veeam Service Provider Console Veeam Updater Plugin

**Veeam Service Provider Console Veeam Updater Plugin** integrates Veeam Service
Provider Console with the Veeam Updater service. This Chocolatey package
installs the Veeam Updater Plugin for VSPC from the Veeam Service Provider
Console ISO.

Veeam Updater helps keep Veeam installations secure and up to date by
automatically installing the latest security updates. Optional updates,
including minor product releases, can also be enabled where appropriate.

**Please Note**: This is an automatically updated package. If you find it is
out of date by more than a day or two, please contact the maintainer(s) and
let them know
[package update issues](https://github.com/mkevenaar/chocolatey-packages/issues)
that the package is no longer updating correctly.
