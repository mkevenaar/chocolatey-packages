## Description

DEPRECATED!

### Quick and easy granular recovery for SharePoint

Microsoft SharePoint has traditionally been one of the most difficult
applications for performing granular recovery and eDiscovery. Veeam® turns this
around with Veeam Explorer™ for Microsoft SharePoint, which is a free tool that
enables fast, easy restores of SharePoint sites, documents, libraries and lists;
all with no agents to manage and no additional licenses to buy
