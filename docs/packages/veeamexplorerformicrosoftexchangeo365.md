## Description

DEPRECATED!

### Recovery tool for Microsoft Exchange

Veeam® Explorer™ for Microsoft Exchange offers revolutionary technology that
gives you instant visibility into Exchange backups, granular recovery of
individual items and easy-to-use eDiscovery options — all without restoring the
full Exchange database or entire server.
