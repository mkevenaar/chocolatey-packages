## Usage

To install Veeam Updater Plug-in for Veeam ONE, run the following command from the command line or from PowerShell:

```powershell
choco install veeam-one-updater-plugin
```

To upgrade Veeam Updater Plug-in for Veeam ONE, run the following command from the command line or from PowerShell:

```powershell
choco upgrade veeam-one-updater-plugin
```

To uninstall Veeam Updater Plug-in for Veeam ONE, run the following command from the command line or from PowerShell:

```powershell
choco uninstall veeam-one-updater-plugin
```

## Exit when reboot detected

When installing / upgrading these packages, I would like to advise you to enable this feature `choco feature enable -n=exitOnRebootDetected`

## Veeam ONE Veeam Updater Plugin

**Veeam ONE Veeam Updater Plugin** integrates Veeam ONE with the Veeam Updater service. This Chocolatey package installs the Veeam Updater Plugin for VeeamONE from the Veeam ONE ISO.

Veeam Updater helps keep Veeam installations secure and up to date by automatically installing the latest security updates. Optional updates, including minor product releases, can also be enabled where appropriate.

**Please Note**: This is an automatically updated package. If you find it is
out of date by more than a day or two, please contact the maintainer(s) and
let them know [here](https://github.com/mkevenaar/chocolatey-packages/issues) that the package is no longer updating correctly.
