## Usage

To install IrfanView All Plugins (Install), run the following command:

```powershell
choco install irfanviewplugins
```

To upgrade IrfanView All Plugins (Install), run the following command:

```powershell
choco upgrade irfanviewplugins
```

To uninstall IrfanView All Plugins (Install), run the following command:

```powershell
choco uninstall irfanviewplugins
```
