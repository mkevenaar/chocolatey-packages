## Usage

To install VIOFO Player, run the following command:

```powershell
choco install viofo-player
```

To upgrade VIOFO Player, run the following command:

```powershell
choco upgrade viofo-player
```

To uninstall VIOFO Player, run the following command:

```powershell
choco uninstall viofo-player
```

## Description

VIOFO Player plays dash camera recordings on your computer alongside GPS routes,
speed and G-sensor data.

### Features

- Play recorded dash camera videos.
- View GPS routes, speed and G-sensor data.
- Capture screenshots and trim videos.
- Combine multiple video streams and customize video exports.

### Notes

- Requires 64-bit Windows and administrator rights.
- Downloads the installer directly from VIOFO; the installer is not embedded in
  this package.
- VIOFO reuses the current download URL. Older package versions may stop
  installing when the upstream file changes.
- Upgrades download and verify the new installer before removing the previous
  installation, then reinstall in the same directory.
