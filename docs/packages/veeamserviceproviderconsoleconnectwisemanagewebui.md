## Usage

To install Veeam Service Provider Console Application Server Web UI for Veeam
ConnectWise Manage Plugin, run the following command:

```powershell
choco install veeam-service-provider-console-connectwise-manage-webui
```

To upgrade Veeam Service Provider Console Application Server Web UI for Veeam
ConnectWise Manage Plugin, run the following command:

```powershell
choco upgrade veeam-service-provider-console-connectwise-manage-webui
```

To uninstall Veeam Service Provider Console Application Server Web UI for Veeam
ConnectWise Manage Plugin, run the following command:

```powershell
choco uninstall veeam-service-provider-console-connectwise-manage-webui
```

## Description

Exit when reboot detected

When installing / upgrading these packages, I would like to advise you to enable
this feature `choco feature enable -n=exitOnRebootDetected`

### VSPC Integration with ConnectWise Manage

_Veeam Service Provider Console_ offers built-in integration with _ConnectWise
Manage_ to combine the functionality of both products and consolidate client
data in one place.
