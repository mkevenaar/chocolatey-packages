## Usage

To install Game Collector, run the following command:

```powershell
choco install game-collector
```

To upgrade Game Collector, run the following command:

```powershell
choco upgrade game-collector
```

To uninstall Game Collector, run the following command:

```powershell
choco uninstall game-collector
```
