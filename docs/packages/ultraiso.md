## Usage

To install UltraISO, run the following command:

```powershell
choco install ultraiso
```

To upgrade UltraISO, run the following command:

```powershell
choco upgrade ultraiso
```

To uninstall UltraISO, run the following command:

```powershell
choco uninstall ultraiso
```

## Description

UltraISO  is an ISO CD/DVD image file creating/editing/converting tool and a
bootable CD/DVD maker , it can directly edit the CD/DVD image file and extract
files and folders from it, as well as directly make ISO files from your
CD/DVD-ROM or  hard disk. At the same time, you can maintain the ISO bootable
information, thus creating your own bootable CD/DVDs.
