## Usage

To install Samsung Magician, run the following command:

```powershell
choco install samsung-magician
```

To upgrade Samsung Magician, run the following command:

```powershell
choco upgrade samsung-magician
```

To uninstall Samsung Magician, run the following command:

```powershell
choco uninstall samsung-magician
```

## Description

Manage your drive like magic
Reaching the maximum potential and proficiency of your Samsung SSD is easy. With
the advanced Magician software, an exclusive set of essential tools equip you
like a pro. Stay ahead with automatic updates, check drive health and speed, and
enable speed boosting RAPID Mode, all with one simple download.
