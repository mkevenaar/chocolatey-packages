## Usage

To install Windows Repair (Portable), run the following command:

```powershell
choco install windowsrepair.portable
```

To upgrade Windows Repair (Portable), run the following command:

```powershell
choco upgrade windowsrepair.portable
```

To uninstall Windows Repair (Portable), run the following command:

```powershell
choco uninstall windowsrepair.portable
```

## Description

An all-in-one repair tool to help fix a large majority of known Windows problems
including registry errors and file permissions as well as issues with Internet
Explorer, Windows Update, Windows Firewall and more.

This package installs the freeware version.
