## Usage

To install Veeam helpers extension, run the following command:

```powershell
choco install veeam.extension
```

To upgrade Veeam helpers extension, run the following command:

```powershell
choco upgrade veeam.extension
```

To uninstall Veeam helpers extension, run the following command:

```powershell
choco uninstall veeam.extension
```

## Description

This package provides helper functions useful for deploying Veeam software from
ISO files.
These functions may be used in Chocolatey install/uninstall scripts by declaring
this package a dependency in your package's nuspec.

**NOTE**: This package requires PowerShell 3 or higher
