## Usage

To install AnyRail6, run the following command:

```powershell
choco install anyrail6
```

To upgrade AnyRail6, run the following command:

```powershell
choco upgrade anyrail6
```

To uninstall AnyRail6, run the following command:

```powershell
choco uninstall anyrail6
```

## Description

AnyRail makes model railroad design so easy, it's fun!

AnyRail™ is probably the easiest-to-use model railway design tool around. It's
also entirely independent, so you can build with almost any track. Enjoy
designing your layout - AnyRail ensures everything fits. AnyRail enables you to
rocket through the planning phase, or tinker to your heart's content - you don't
have to be a computer expert to produce successful designs.
