## Usage

To install Chocolatey ISO helpers extension, run the following command:

```powershell
choco install chocolatey-isomount.extension
```

To upgrade Chocolatey ISO helpers extension, run the following command:

```powershell
choco upgrade chocolatey-isomount.extension
```

To uninstall Chocolatey ISO helpers extension, run the following command:

```powershell
choco uninstall chocolatey-isomount.extension
```

## Description

This package provides helper functions useful for deploying software from ISO
files.
These functions may be used in Chocolatey install/uninstall scripts by declaring
this package a dependency in your package's nuspec.

**NOTE**: This package requires PowerShell 3 or higher
