## Usage

To install Openfire, run the following command:

```powershell
choco install openfire
```

To upgrade Openfire, run the following command:

```powershell
choco upgrade openfire
```

To uninstall Openfire, run the following command:

```powershell
choco uninstall openfire
```

## Description

Openfire is a real time collaboration (RTC) server licensed under the Open
Source Apache License. It uses the only widely adopted open protocol for instant
messaging, XMPP (also called Jabber). Openfire is incredibly easy to setup and
administer, but offers rock-solid security and performance.
