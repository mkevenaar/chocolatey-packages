## Usage

To install Plex Media Server, run the following command:

```powershell
choco install plexmediaserver
```

To upgrade Plex Media Server, run the following command:

```powershell
choco upgrade plexmediaserver
```

To uninstall Plex Media Server, run the following command:

```powershell
choco uninstall plexmediaserver
```

## Description

Plex Media Server works with the family of Plex apps, as well as other DLNA
clients to make your PC-connected media accessible from all of your devices.

**Please Note**: This is an automatically updated package. If you find it is
out of date by more than a day or two, please contact the maintainer(s) and
let them know
[package update issues](https://github.com/mkevenaar/chocolatey-packages/issues)
that the package is no longer updating correctly.
