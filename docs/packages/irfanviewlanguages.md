## Usage

To install IrfanView All Languages (Install), run the following command:

```powershell
choco install irfanview-languages
```

To upgrade IrfanView All Languages (Install), run the following command:

```powershell
choco upgrade irfanview-languages
```

To uninstall IrfanView All Languages (Install), run the following command:

```powershell
choco uninstall irfanview-languages
```
