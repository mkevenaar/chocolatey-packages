## Usage

To install AppVeyor Server (Team Edition), run the following command:

```powershell
choco install appveyor-server
```

To upgrade AppVeyor Server (Team Edition), run the following command:

```powershell
choco upgrade appveyor-server
```

To uninstall AppVeyor Server (Team Edition), run the following command:

```powershell
choco uninstall appveyor-server
```

## Description

AppVeyor CI on your own server

Install in minutes on Windows, Linux or Mac. Run unlimited pipelines locally, in
Docker or any cloud.

- Works with GitHub, Bitbucket, GitLab, Azure Repos or your favorite source
  control
- Run Windows and Linux builds in parallel in the same Docker pipeline
- Run builds on Azure, AWS or GCP and pay for build minutes only
- Free for unlimited users, projects, jobs, clouds and agents
