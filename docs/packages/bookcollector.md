## Usage

To install Book Collector, run the following command:

```powershell
choco install book-collector
```

To upgrade Book Collector, run the following command:

```powershell
choco upgrade book-collector
```

To uninstall Book Collector, run the following command:

```powershell
choco uninstall book-collector
```
