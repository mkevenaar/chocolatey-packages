# <img src="https://cdn.jsdelivr.net/gh/mkevenaar/chocolatey-packages@4c4f6926c662700aa43b59b00b8d84ec4049f53c/icons/viofo-player.png" width="48" height="48"/> [viofo-player](https://community.chocolatey.org/packages/viofo-player)

VIOFO Player plays dash camera recordings on your computer alongside GPS routes, speed and G-sensor data.

## Features

- Play recorded dash camera videos.
- View GPS routes, speed and G-sensor data.
- Capture screenshots and trim videos.
- Combine multiple video streams and customize video exports.

## Notes

- Requires 64-bit Windows and administrator rights.
- Downloads the installer directly from VIOFO; the installer is not embedded in this package.
- VIOFO reuses the current download URL. Older package versions may stop installing when the upstream file changes.
- Upgrades download and verify the new installer before removing the previous installation, then reinstall in the same directory.
